# Poster Trail

그래픽 아카이브 이미지를 움직이는 영상으로 만드는 브라우저 앱입니다.
업로드한 프로젝트의 React 화면과 애니메이션 소스를 그대로 사용합니다.

## 실행

Node.js 22 이상에서:

```sh
npm ci
npm run dev
```

이미지를 업로드하고 트레일, 버스트, 공전, 반발, 중력, 축구, 컷 모드를 선택하세요.
캔버스 비율과 모드별 설정을 조절할 수 있습니다.
`R` 키로 녹화를 시작하고, 다시 `R`을 누르면 영상을 다운로드합니다.
브라우저 지원에 따라 MP4 또는 WebM으로 저장됩니다.
이미지는 브라우저 메모리에서 처리되며 서버로 업로드되지 않습니다.

영상 출력 해상도는 창 크기와 관계없이 고정됩니다: 9:16은 1080×1920,
1:1은 1080×1080, 16:9는 1920×1080, 4:5는 1080×1350입니다.
컷 모드의 이미지 위치와 크기도 고정 출력 좌표를 기준으로 저장됩니다.

## 컷 모드 자동 녹화

이미지를 업로드한 뒤 전환 속도와 녹화 반복 횟수(1~100회)를 설정하고
**자동 녹화·다운로드**를 누르세요. 첫 이미지부터 업로드 순서대로 지정한 횟수만큼
재생한 뒤 녹화를 종료하고 영상을 자동 다운로드합니다.
예를 들어 10장, 초당 2장, 3회 반복이면 약 15초 영상이 저장됩니다.
수동 미리보기 모드에서도 자동 녹화는 설정한 속도로 진행됩니다.
녹화 중에는 설정 변경이 잠기며, **녹화 종료·저장**으로 중간에 끝낼 수 있습니다.

## 컷 모드 일괄 영상 생성

1,000장을 업로드하고 **영상당 이미지 수 10**, **각 영상 반복 횟수 3**으로 설정한 뒤
**일괄 녹화·ZIP 다운로드**를 누르면 영상 100개가 `poster_reels.zip`에 저장됩니다.
파일명을 숫자 순서로 정렬하며, 영상 이름은 `01-10.mp4`, `11-20.mp4`, …,
`991-1000.mp4`처럼 실제 원본 파일명의 범위로 정합니다. 마지막에 남는 이미지도 영상으로 만듭니다.
브라우저가 MP4 녹화를 지원하지 않으면 실제 형식인 `.webm`으로 저장합니다.

녹화는 현재 전환 속도로 순서대로 진행됩니다. 1,000장 × 3회 ÷ 초당 2장은 약 25분입니다.
현재 묶음과 완료 영상 개수를 표시합니다. 다른 탭으로 이동하면 자동 녹화를 일시정지하고
돌아오면 이어서 진행합니다. 페이지를 닫거나 새로고침하면 진행 내용이 사라집니다.
**일괄 중단·완료 영상 저장**을 누르면 이미 완성된 영상만 ZIP으로 다운로드합니다.
아직 녹화 중인 묶음은 포함하지 않습니다. ZIP 완성 전까지 영상 데이터는 브라우저 메모리에 보관합니다.

## 테스트

```sh
npm test
```

숫자 정렬, 1,000장 분할, 마지막 묶음 및 파일명 처리를 검증합니다.

## 빌드와 배포

```sh
npm run build
npm run preview
```

GitHub 저장소의 **Settings → Pages → Build and deployment → Source**를
**GitHub Actions**로 설정하세요. `main`에 푸시하면 Pages 배포 워크플로가 실행됩니다.
설정을 변경한 뒤에는 Actions에서 **Deploy to GitHub Pages → Run workflow**로 다시 실행할 수 있습니다.
배포가 성공하면 Pages 설정이나 워크플로에 실제 사이트 주소가 표시됩니다.

Windows에서 제공된 `실행.bat`도 사용할 수 있습니다.
